# Security Policy

## Supported versions

Security fixes are considered for the current default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately to **[INSERT SECURITY CONTACT BEFORE PUBLIC RELEASE]** and include:

- a clear description and impact;
- reproduction steps or a proof of concept;
- affected version, operating system, and relevant configuration; and
- any known mitigation.

This project includes robot-control code. Safety concerns involving motion, torque, contact behavior, or hardware interfaces should also be reported privately until maintainers can assess them.
