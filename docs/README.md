The documents are sorted by what they are for:

- **Final task:** what the project is building now.
- **Setup:** how the environment, workcell and hardware were brought up. Still valid reference.
- **Legacy:** what we used in the past to get started, and claims that are no longer true.

Start with the final task folder.
