# GroundingDINO (text-prompted detection) + SAM2 (segmentation) for src/vision/object_localizer.py.
# Install into the project venv on the machine that runs the camera (a CUDA GPU is recommended):
#
#   1) torch / torchvision matching your GPU, e.g. for CUDA 12.8 (RTX 50-series):
#        pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#      (CPU / macOS: pip install torch torchvision)
#   2) pip install --no-build-isolation -r requirements-vision.txt   (both build against the installed torch)
#   2b) GroundingDINO pulls in plain opencv-python, which shadows the contrib build (cv2.aruco):
#        pip uninstall -y opencv-python && pip install --force-reinstall opencv-contrib-python
#   3) model weights into weights/ (Git-ignored): scripts/download_vision_weights.sh
#
# The Docker image does all of this with: ROBOTOKENS_VISION=1 docker/dev.sh build
